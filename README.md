# AI Resume Analyzer

An AI-powered tool that analyzes resumes and gives instant feedback using Google Gemini AI.

## Features
- Upload Resume PDF
- Get ATS Score
- Skill Gap Analysis
- Suggestions to Improve Resume

## Libraries Used
- streamlit
- google-genai (from google import genai)
- PyPDF2
- os

## How to Run
1. Clone this repo
2. Create a .env file and add your GOOGLE_API_KEY
3. Install libraries: pip install streamlit google-genai PyPDF2 python-dotenv
4. Run: streamlit run AI_resume_Analyzer.py
